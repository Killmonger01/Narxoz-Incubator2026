# Тянем‑Потянем — перетягивание каната в браузере

**Играть:** https://kanat.tyanem-potyanem.workers.dev
**Репозиторий:** https://github.com/Killmonger01/Narxoz-Incubator2026
**Тестовый аккаунт:** `demo` / `demo123` (или зарегистрируйтесь за 10 секунд)

Задание второго этапа Narxoz Incubator 2026 — «Перетягивание каната».

## Что это и для кого

Короткая соревновательная игра для студентов и школьников: матч на минуту, в который можно сыграть на перемене с соседом
по парте, с ботом или с другом по ссылке с другого телефона.

Главная идея: **побеждает не тот, кто быстрее жмёт, а тот, кто держит ритм, бережёт силы и выбирает момент для рывка.**
Кнопку «Тянуть» можно спамить, но спам выжигает выносливость за пару секунд, и даже бот «Новичок» обыгрывает такого игрока
(это проверено симуляцией, см. ниже). Хорошая игра — это ритм, отдых в нужный момент, рывок, когда соперник выдохся,
и упор, когда у соперника заряжен рывок.

## Правила

Посередине каната — красная отметка. У каждой команды своя цветная линия.
**Перетяни отметку за свою линию — раунд твой.**

- Раунд длится 45 / 60 / 90 секунд. Если никто не перетянул, побеждает сторона, на чьей половине отметка.
  Если отметка ближе 10% к центру — ничья.
- Серия: 1 раунд, до 2 или до 3 побед. Ничейный раунд не засчитывается никому (максимум `bestOf + 2` раундов).
- Перед стартом — отсчёт 3‑2‑1. Нажатия до старта и после финиша игнорируются.

### Четыре действия

| Действие | Клавиатура (соло и онлайн) | Что делает |
|---|---|---|
| **Тянуть** | Пробел или A | Одна тяга на нажатие. Удержание не работает (автоповтор игнорируется), нажатия чаще ~8.5/с отбрасываются. Стоит 6 выносливости. |
| **Ритм** | — | Кольцо над канатом бьёт 100 раз в минуту. Тяга в «зелёное окно» (±100 мс) **в 3 раза сильнее** и стоит 4 выносливости. Тяги в ритм подряд копят серию. |
| **Рывок** | D | Каждая тяга в ритм заряжает шкалу на 25%. Полная шкала — мощный рывок (15 выносливости). Если соперник отдыхает или выдохся — **«Срыв!» ×1.5**. Если он в упоре — **«Отбит!»**, рывок теряет большую часть силы. |
| **Упор** | S (держать) | Через 100 мс соперник тянет в 2.5 раза слабее. В упоре нельзя тянуть, силы тратятся (5/с). |
| Пауза | Esc / P | Только в локальных режимах. |

На телефоне и планшете — большие кнопки «Тянуть / Рывок / Упор» внизу экрана.
В режиме «вдвоём на одном устройстве»: левый игрок **A / S / D**, правый **L / K / J**; на сенсорном экране у каждого свои
кнопки у своего края.

### Выносливость

- Чем меньше выносливости, тем слабее тяга (до −45%).
- Потратил всё — **«Выдохся»**: 1.5 с нельзя ничего делать.
- Восстановление начинается, если 0.4 с не тянуть и не упираться. Но пока ты отдыхаешь, соперник тянет свободно — отсюда
  главный выбор: когда давить, а когда восстановиться.
- Ритм почти самоокупаем (между ударами ты успеваешь немного восстановиться), а спам «на скорость» выжигает силы.

## Режимы

- **Обучение** — пошаговая тренировка с манекеном: тяга → ритм → рывок → упор → отдых. Прогресс засчитывается по реальным
  действиям в игре, а не по кнопке «Далее».
- **Против бота** — 4 уровня: Новичок, Любитель, Капитан, Чемпион. Серии раундов. После матча — статистика и совет
  тренера по тому, как ты реально играл («в ритм попало только 33%…»).
- **Вдвоём на одном устройстве** — клавиатура пополам или телефон на столе.
- **Испытания** — «Метроном» (самая длинная серия в ритм), «Спринт» (перетянуть манекен быстрее всех), «Выстоять против
  Чемпиона», «Камбэк» (отыграться, когда канат почти у твоей линии). Личные рекорды.
- **Онлайн** — комната по ссылке 1×1, свободное место можно отдать боту, режим зрителя, рейтинг Эло.

### Как сыграть онлайн

1. Главная → «Онлайн с другом» → выбрать формат → «Создать и пригласить».
2. Нажать «Пригласить» — ссылка вида `/r/K7QXM` копируется (на телефоне открывается меню «Поделиться»).
3. Друг открывает ссылку на своём устройстве, вводит имя (или входит в аккаунт) и попадает в комнату.
   Можно также ввести 5‑символьный код в разделе «Онлайн».
4. Оба нажимают «Я готов!» — начинается отсчёт. После серии — «Реванш».
5. Хозяин комнаты может посадить бота на пустое место, если друг не пришёл.
6. Зритель: «Онлайн» → «Идут сейчас» → «Смотреть», или ссылка комнаты с `?watch=1`.

**Отключение.** Если игрок теряет соединение во время матча, игра встаёт на паузу у всех и ждёт 15 секунд. Вернулся
(та же вкладка или тот же аккаунт) — 3 секунды отсчёта и игра продолжается. Не вернулся — техническое поражение.

## Честность и защита от обхода правил

- **Одна и та же логика везде.** Движок [src/shared/engine.ts](src/shared/engine.ts) — чистые функции без DOM и таймеров.
  Его используют браузер (локальные режимы), бот и сервер (онлайн).
- **Фиксированный шаг 60 Гц.** Скорость игры не зависит от FPS: на 144 Гц мониторе канат движется так же, как на 60 Гц.
  После долгого кадра (вкладка была скрыта) игра не «догоняет» время, а в локальных режимах встаёт на паузу.
- **Ввод:** удержание не даёт тяг (игнорируется `KeyboardEvent.repeat`), минимальный интервал между тягами — 7 тиков,
  без выносливости тянуть нельзя, ввод до старта и после финиша отбрасывается.
- **Онлайн — авторитетный сервер.** Клиент отправляет только намерения (`pull`, `burst`, `brace`). Комната на сервере сама
  проверяет их тем же движком, двигает время, определяет победителя и пишет результат в базу. Клиент не может
  передвинуть канат, потратить больше выносливости или объявить победу.
  - Компенсация задержки: ритм оценивается в момент нажатия у клиента, но только в окне 150 мс в прошлое и строго
    монотонно — одно нажатие нельзя засчитать дважды.
  - Флуд‑лимит: 40 сообщений в секунду на соединение. В тесте клиент, отправивший 1560 сообщений с «тиками из будущего»,
    получил 4 засчитанные тяги и проиграл.
- **Бот играет по тем же правилам**: вызывает тот же `applyAction`, тратит выносливость, выдыхается, реагирует с задержкой
  (160–600 мс в зависимости от уровня) и видит только то, что видно на экране (полоски сил, заряд рывка).
- **Рейтинг** считается только по онлайн‑матчам, которые определил сервер. Матчи с ботом и «вдвоём» сохраняются в историю
  с пометкой «не проверено сервером» и на рейтинг не влияют.

### Баланс (симуляция)

`npm run sim` прогоняет тысячи матчей без графики. Результаты (доля побед левой стороны):

| Матч | Победы |
|---|---|
| Новичок vs Любитель | 0–2% |
| Любитель vs Капитан | 1–2% |
| Капитан vs Чемпион | ~23% |
| Спам на максимальной скорости vs Новичок | 0% |
| «Удержание кнопки» vs Новичок | 0% |
| Точный ритм ±33 мс + отдых vs Капитан | ~63% |
| Точный ритм ±33 мс + отдых vs Чемпион | ~14% |

## Аккаунты, история, статистика

- Регистрация по нику и паролю (PBKDF2‑SHA256, 100 000 итераций, соль). Сессия — случайный токен, в базе хранится только его
  SHA‑256‑хеш, срок 30 дней.
- Профиль: победы/поражения по режимам, процент побед, рекорды испытаний, история последних 50 матчей с процентом тяг
  в ритм и изменением рейтинга. Войдите с другого устройства — история та же.
- Без аккаунта всё работает: настройки, история и рекорды хранятся в `localStorage`.
- Рейтинг игроков (Эло, K=32; меняется только в онлайн-матчах, где оба игрока вошли в аккаунт).

## Монетизация (тестовый режим)

**Pro — 990 ₸/месяц**. Pro меняет только внешний вид и **не даёт преимуществ** в игре:

- 3 арены (ночной стадион, пляж Капчагая, Медеу зимой), 3 каната, 3 цвета команды;
- в онлайн‑комнате все видят арену и канат хозяина комнаты — это и есть «витрина» Pro для друзей;
- значок PRO в рейтинге.

Оплата работает в **явно обозначенном тестовом режиме**, устроенном как тестовая среда платёжного провайдера:

- касса с полями «номер карты / срок / CVC / имя»: номер проверяется по алгоритму Луна, срок — на актуальность,
  определяется платёжная система (Visa / Mastercard);
- тестовые карты: `4242 4242 4242 4242` — успех, `4000 0000 0000 0002` — «отказ банка»; реальные карты не принимаются;
- сервер валидирует данные, продлевает Pro на 30 дней, записывает платёж (`mode = 'test'`, хранятся только последние
  4 цифры) и возвращает чек с номером платежа, суммой, датой и сроком действия Pro;
- предметы открываются сразу; кнопка «Отменить (тест)» возвращает всё назад, чтобы проверить повторно.

Настоящий провайдер (Stripe, Kaspi Pay и т.п.) подключается на место `/api/shop/test-purchase` без изменения клиента.

Дальше по плану: Pro‑кабинет организатора — турнирные сетки и приватные турниры для мероприятий.

## Технологии

- **Frontend:** React 19, TypeScript, Vite, Canvas 2D (вся графика рисуется кодом), WebAudio (все звуки синтезируются,
  аудиофайлов нет).
- **Backend:** Cloudflare Workers (REST API), **Durable Objects** (одна комната = один объект, WebSocket, авторитетный
  игровой цикл), **D1** (SQLite: пользователи, сессии, матчи, рекорды, платежи, комнаты).
- Шрифт Rubik (Google Fonts).

### Структура

```
src/shared/engine.ts      игровая логика (общая для клиента, бота и сервера)
src/shared/bot.ts         компьютерный соперник, 4 уровня
src/shared/protocol.ts    сообщения клиент ↔ комната
src/worker/index.ts       REST API: auth, профиль, матчи, рейтинг, магазин, комнаты
src/worker/room.ts        Durable Object комнаты: лобби, матч, пауза, реванш, запись результатов
src/client/game/          отрисовка, драйверы (локальный / онлайн), экраны матча, обучение
src/client/screens/       меню, профиль, рейтинг, магазин, настройки
migrations/               схема D1
scripts/sim.ts            симуляция баланса
```

## Запуск локально

Нужен Node.js 20+.

```bash
npm install
npm run db:migrate:local     # создать локальную SQLite-базу
npm run build                # собрать фронтенд в dist/
npx wrangler dev             # http://localhost:8787 — игра + API + WebSocket
```

Для разработки интерфейса с горячей перезагрузкой: `npx wrangler dev` в одном терминале и `npm run dev` во втором
(Vite на :5173 проксирует `/api` и `/ws` на :8787).

Симуляция баланса: `npm run sim`.

### Деплой

Рабочая версия: https://kanat.tyanem-potyanem.workers.dev (Cloudflare Workers; фронтенд, API, WebSocket и база — в одном деплое).

```bash
npx wrangler login
npx wrangler d1 create kanat-db          # вписать database_id в wrangler.jsonc
npm run db:migrate:remote
npm run deploy
```

Копия фронтенда на Vercel (https://narxoz-incubator2026.vercel.app) не содержит серверной части: там работают только режимы
против бота и вдвоём на одном устройстве.

## Известные ограничения

- Результаты матчей с ботом и испытаний отправляет клиент — их можно подделать, поэтому они не влияют на рейтинг.
- Компенсация задержки для ритма ограничена 150 мс; при пинге выше ритм в онлайне ощущается хуже.
- Состояние комнаты хранится в памяти Durable Object: если Cloudflare перезапустит объект посреди матча, текущий матч
  пропадёт (комнату можно создать заново). Сохранённые результаты не теряются.
- Движок и серверная комната умеют командные матчи (несколько игроков на сторону), но в продукте это не включено.
- Турниры, друзья и Pro‑кабинет организатора — пока в планах.
